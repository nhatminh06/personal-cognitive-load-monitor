# Security audit executive summary

Audit date: 2026-10-25. Scope: the local repository and its Git history, application, data platform, containers, Helm, Terraform and CI/CD configuration. No cloud workload was provisioned or deployed.

The review found no committed credential matching the tested high-confidence token/private-key patterns. It did find material weaknesses: production-sensitive APIs could run without authentication, raw poison messages were copied into a DLQ, a joblib artifact had no integrity gate, CI permissions and deployment scope were too broad, build arguments could carry secrets, development services listened on all interfaces, Redis had no authentication, and the lockfile contained published vulnerabilities.

The local fixes are implemented and covered by regression tests. Python tests pass (76 tests, 88.67% combined package coverage), Ruff and scoped MyPy pass, DVC is reproducible, all four notebooks execute, Compose and all Helm value sets validate, and Terraform formatting and provider-backed validation pass. Airflow 3.3.2 completed the actual six-task DAG without a Docker socket; all 91 objects (105,683 bytes) were hash-verified after migration from the preserved MinIO volume to SeaweedFS 4.50; Spark/Delta, Trino and two dbt runs passed against the replacement endpoint.

Release decision: **LOCALLY READY, SUBJECT TO REQUIRED PR CHECKS**. SEC-018 through SEC-021 are remediated, including GitHub protection read-back. Exact-digest scans rejected official Spark 3.5.9 and 4.1.3 candidates because each contains hundreds of High/Critical findings, both with and without reported fixes. The source-rebuild proof is blocked, so SEC-022 is accepted—not remediated—only for isolated local development through 2027-01-23. Immutable CI digest deployment and SeaweedFS raw-control-plane isolation are implemented and locally checked. SEC-011 and KServe artifact enforcement remain cloud-deferred; the exception does not authorize production deployment.
