## Guarantees and next gate

Redis freshness prevents an older feature from replacing a newer one in this test. A single broker, local plaintext loopback gateway, 24-hour Flink dedup TTL and Redis AOF are not cloud/HA guarantees. The current production Cloudflare Worker/D1 has no outbox migration or scheduler; G1B.3 Worker Free CPU remains unverified. `DEFER_SPARK_ENFORCED` and `DEFER_KFP` remain active.
