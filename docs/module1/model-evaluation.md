# Model evaluation

The current engineering comparison evaluates a majority dummy, logistic
regression, and random forest on deterministic chronological timestamp groups:
60% training, 20% validation, and 20% previously observed audit data. It records
accuracy, macro-F1, per-class metrics, confusion matrices, exact split identity,
and explicit `synthetic_proxy` provenance. The audit partition is not independent
and is never used for selection.

`reports/metrics.json` records validation accuracy/macro-F1 of 0.65/0.262626 for
the dummy, 0.86/0.803636 for logistic regression, and 0.90/0.880061 for random
forest. The declared selection rule chooses validation macro-F1, then accuracy,
then a simple-to-complex tie order. This new engineering run does not mutate or
approve registry versions 1–11, and its results must not be attributed to them.
See [`model-selection-policy.md`](model-selection-policy.md).

These labels are generated by the demonstration rule. Scores measure rule
fidelity, not cognition, wellbeing, productivity, or medical state. The separate
focus-session contract uses opt-in 1–7 `self_reported_effort`; it is not training
or validation evidence for this classifier. No participant data was used here.
