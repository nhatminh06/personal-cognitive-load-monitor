# Model evaluation

Success criteria were set before the final run: compare a majority dummy, Logistic Regression and Random Forest on the same chronological 80/20 split; report accuracy, macro-F1, per-class recall and confusion matrices; require an explicit `synthetic_proxy` label source and dataset SHA-256.

The final checked run registered `cognitive-load-classifier` version 4, run ID `f701a0ac02b241558dfd943dbc6d9508`. Logistic Regression scored 0.960 accuracy/0.951 macro-F1 and Random Forest 0.880/0.868. The generating-rule baseline is necessarily 1.0, demonstrating proxy-label leakage rather than validity. Full tables are in `reports/metrics.json`.

These labels are generated by the demonstration rule. Scores measure how well a model reproduces that rule, not cognition, wellbeing, productivity, or medical state. A future `self_report` path must be opt-in, consented, limited to a defined 1–5 range, separately retained/deleted, and marked with `self_report` provenance. No participant data was collected here.
