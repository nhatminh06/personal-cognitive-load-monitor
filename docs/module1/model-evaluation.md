# Model evaluation

The current engineering comparison evaluates a majority dummy, logistic
regression, and random forest on the same chronological 80/20 split. It records
accuracy, macro-F1, per-class recall and confusion matrices with explicit
`synthetic_proxy` provenance and a dataset SHA-256. No retained evidence proves
that selection thresholds were predeclared before the results were observed.

`reports/metrics.json` records logistic regression at 0.960 accuracy/0.951469
macro-F1 and random forest at 0.880/0.867836. Registry versions 8 and 10 carry
this evaluation shape and dataset digest; the previous version-4 attribution is
not supported by the current registry record. The selected random forest is not
justified by these metrics, but the test partition must not now be reused to
select logistic regression. The rule result is `metrics(y_test, y_test)`, an
identity check rather than an executed predictive baseline. See
[`model-selection-policy.md`](model-selection-policy.md).

These labels are generated by the demonstration rule. Scores measure rule
fidelity, not cognition, wellbeing, productivity, or medical state. The separate
focus-session contract uses opt-in 1–7 `self_reported_effort`; it is not training
or validation evidence for this classifier. No participant data was used here.
